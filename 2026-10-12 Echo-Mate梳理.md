## DeskBot配置

### DeskBot 仿真配置

- 没有真实硬件改成在电脑窗口里模拟
```
#define LV_USE_SIMULATOR 1
```

### DeskBot 编译依赖

```
SDL2：LVGL Simulator -> 窗口 -> 鼠标/键盘/显示

ALSA / PortAudio:麦克风 + 扬声器

websocketpp：DeskBot -> WebSocket -> AIChat Server

opus：负责语音数据编码
format = opus
sample_rate = 16000
channels = 1
frame_duration = 40

**Opus 编码器**：PCM（原始音频） → Opus（Opus 编码）  
**Opus 解码器**：Opus → PCM

ASR 和 TTS：声音转文字和文字转声音

jsoncpp / json-c：负责各种 JSON 数据解析
ASR结果
↓
{"type":"asr","text":"你好"}
```

## 配置问题

### PyTorch 和 torchaudio

- 优先让 torch / torchaudio 版本匹配，而不是看到最新版本就全部升级
```
torch
  ↓
决定 PyTorch 核心版本

torchaudio
  ↓
必须和 torch 大体对应

CUDA Runtime
  ↓
又决定底层动态库
```

### ffmpeg

- 音频/媒体处理的基础工具
```
Couldn't find ffmpeg or avconv

Python 能 import，不代表：系统里相关命令/动态库就一定存在
Python依赖 + 系统依赖
```

### 小问题

- AIChat_protocol_version=2
```
DeskBot 和 Server 按哪一套 AIChat 通信协议进行通信

TCP/WebSocket ↓ 协议版本 ↓ hello ↓ token ↓ 音频参数 ↓ ASR ↓ Thinking ↓ LLM
protocol=2已经通过了实际认证和音频参数交换
```

- IP问题
```
DeskBot + AIChat Server
同一个 Ubuntu 虚拟机环境所以：127.0.0.1

真实开发板：电脑局域网 IP
```

- APIkey
```
新 Key ↓ 长度超过缓冲区 ↓ 写入时被截断 ↓ 保存/读取异常
```

